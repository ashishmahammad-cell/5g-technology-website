# 5G Technology Website

A responsive, single-page informational website about **5G technology** — built as a **college semester project (March 2024)** using pure **HTML5 and CSS3**. No JavaScript, no frameworks, no libraries.

## 🌐 Live Demo

👉 **[View the live website](https://ashishmahammad-cell.github.io/5g-technology-website/)**

## 📖 About the Project

This project was created as part of my **college semester coursework (March 2024)** to explore 5G technology and practice modern, responsive web design using only fundamental web technologies.

The site presents 5G in **7 chapters**:

| Chapter | Topic |
|---|---|
| 01 | **Introduction** — What 5G is and its 3 pillars (eMBB, URLLC, mMTC) |
| 02 | **Evolution** — From 1G (1979) to 5G (2020) |
| 03 | **Architecture** — Cloud-native, service-based network design |
| 04 | **Global Rollout** — India vs the world (fastest 5G deployment in history) |
| 05 | **Applications** — Healthcare, autonomous vehicles, smart cities |
| 06 | **Myths vs Reality** — What the science actually says |
| 07 | **Statistics** — 2.5B global users, $13.2T projected GDP impact |
