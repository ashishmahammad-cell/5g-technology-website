# 5G Technology Website

A single-page website about 5G technology that I built for my college semester project in March 2024. Used only HTML and CSS. No JavaScript, no frameworks — just the basics.

## Live Site

You can open it here: https://ashishmahammad-cell.github.io/5g-technology-website/

## Why I Made This

For my semester project, I had to pick a technology topic and present it. I chose 5G because it's relevant to India right now — the rollout here has been crazy fast compared to other countries. I didn't want to just make slides, so I decided to build a small website instead. That way the content is something people can actually scroll through.

I kept it to one HTML file so it's easy to open and check. No build tools, no setup, no dependencies.

## What's In It

The site has 7 sections, one after another:

1. **Introduction** — What 5G actually is and its three main pillars (eMBB, URLLC, mMTC)
2. **Evolution** — The jump from 1G in 1979 all the way to 5G in 2020
3. **Architecture** — How 5G networks are built differently from 4G
4. **Global Rollout** — When each country launched 5G and how India compared
5. **Applications** — Real use cases like remote surgery and self-driving cars
6. **Myths vs Reality** — Common 5G myths and what the science actually says
7. **Statistics** — User numbers, market share, economic impact

## Built With

- HTML5 — for the structure
- CSS3 — for all the styling and layout
- Google Fonts — for the two fonts (Syne and DM Sans)
- Unsplash — for the images

That's it. One `index.html` file. Around 200 lines of CSS. No libraries.

## Things That Work

- Opens fine on phone, tablet, and desktop
- Navigation links jump to the right section (no JavaScript — just anchor links)
- Cards use flexbox so they line up nicely on all screen sizes
- Tested in Chrome, Edge, and Firefox
- Passed the W3C HTML validator (no errors)
